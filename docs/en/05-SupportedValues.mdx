# Supported Values

jsoneo supports serializing and deserializing almost everything in JavaScript.

## JSON-Compatible Values

- `string`
- `number`
- `boolean`
- `null`
- Plain objects (including nested objects)
- Arrays (including nested arrays)

## JavaScript-Specific Values

### Special Primitive Values

| Value       | Serialization  | Notes                              |
| ----------- | -------------- | ---------------------------------- |
| `undefined` | Special marker | Not representable in standard JSON |
| `NaN`       | Special marker |                                    |
| `Infinity`  | Special marker |                                    |
| `-Infinity` | Special marker |                                    |
| `-0`        | Special marker | Distinguishes from `+0`            |
| `BigInt`    | Special marker | Preserves precision                |

### Built-in Objects

| Type              | Serialization                        | Notes                                  |
| ----------------- | ------------------------------------ | -------------------------------------- |
| `Date`            | Full precision ISO string + metadata | Restored as `Date` instance            |
| `RegExp`          | Pattern + flags                      | Restored as `RegExp` instance          |
| `URL`             | Full URL string                      | Restored as `URL` instance             |
| `URLSearchParams` | Serialized params                    | Restored as `URLSearchParams` instance |
| `Error`           | Name, message, stack                 | Restored as error instance             |

### Collections

| Type      | Serialization         | Notes                                          |
| --------- | --------------------- | ---------------------------------------------- |
| `Map`     | Key-value pairs       | Keys converted to strings (like plain objects) |
| `Set`     | Array of values       |                                                |
| `WeakMap` | `{}` (structure only) | Entries not enumerable                         |
| `WeakSet` | `[]` (structure only) | Entries not enumerable                         |

### Binary Data

| Type                | Serialization     | Notes                                |
| ------------------- | ----------------- | ------------------------------------ |
| `Int8Array`         | Base64 + metadata |                                      |
| `Uint8Array`        | Base64 + metadata |                                      |
| `Uint8ClampedArray` | Base64 + metadata |                                      |
| `Int16Array`        | Base64 + metadata |                                      |
| `Uint16Array`       | Base64 + metadata |                                      |
| `Int32Array`        | Base64 + metadata |                                      |
| `Uint32Array`       | Base64 + metadata |                                      |
| `Float32Array`      | Base64 + metadata |                                      |
| `Float64Array`      | Base64 + metadata |                                      |
| `BigInt64Array`     | Base64 + metadata |                                      |
| `BigUint64Array`    | Base64 + metadata |                                      |
| `ArrayBuffer`       | Base64 + metadata |                                      |
| `DataView`          | Base64 + metadata |                                      |
| Node.js `Buffer`    | Base64 + metadata | Restored as `Uint8Array` in browsers |

### Functions

| Type                | Serialization           | Notes |
| ------------------- | ----------------------- | ----- |
| Regular functions   | Function body preserved |       |
| Arrow functions     | Function body preserved |       |
| Async functions     | Function body preserved |       |
| Generator functions | Function body preserved |       |
| Methods             | Function body preserved |       |

> **Closure limitation:** Function bodies are serialized, but lexical closures are NOT captured automatically. Use the `closure` option of `parse()` to provide external variables, or attach values to named function objects.

### Symbols

| Type                            | Serialization                               | Notes |
| ------------------------------- | ------------------------------------------- | ----- |
| Well-known symbols              | Name (e.g., `Symbol.iterator`)              |       |
| Global symbols (`Symbol.for()`) | Key string                                  |       |
| Local symbols                   | Description as value                        |       |
| Symbol object keys              | Supported for well-known and global symbols |       |

### Advanced Features

- **Property descriptors** (writable, configurable, enumerable, getters/setters)
- **Prototype chain** (methods and properties on prototype)
- **Circular references** (tracked and restored)
- **Custom `toJSON` / `fromJSON`** methods respected
- **`JSON.rawJSON()`** objects (when runtime supports it)
- **Non-enumerable properties** (when `preserveDescriptors: true`)

## Not Supported

- Private class fields and methods (not accessible from outside)
- Native functions (source is `[native code]`)
- `Function.prototype.bind()` results (become native-like)
- `WeakMap`/`WeakSet` entries (not enumerable)
