# 支持的值类型

jsoneo 支持序列化和反序列化 JavaScript 中几乎所有内容。

## JSON 兼容值

- `string`
- `number`
- `boolean`
- `null`
- 纯对象（包括嵌套对象）
- 数组（包括嵌套数组）

## JavaScript 特有值

### 特殊基础值

| 值          | 序列化方式 | 说明               |
| ----------- | ---------- | ------------------ |
| `undefined` | 特殊标记   | 标准 JSON 不可表示 |
| `NaN`       | 特殊标记   |                    |
| `Infinity`  | 特殊标记   |                    |
| `-Infinity` | 特殊标记   |                    |
| `-0`        | 特殊标记   | 区别于 `+0`        |
| `BigInt`    | 特殊标记   | 保留精度           |

### 内建对象

| 类型              | 序列化方式                 | 说明                          |
| ----------------- | -------------------------- | ----------------------------- |
| `Date`            | 全精度 ISO 字符串 + 元数据 | 恢复为 `Date` 实例            |
| `RegExp`          | 模式 + 标志                | 恢复为 `RegExp` 实例          |
| `URL`             | 完整 URL 字符串            | 恢复为 `URL` 实例             |
| `URLSearchParams` | 序列化参数                 | 恢复为 `URLSearchParams` 实例 |
| `Error`           | 名称、消息、堆栈           | 恢复为错误实例                |

### 集合

| 类型      | 序列化方式     | 说明                     |
| --------- | -------------- | ------------------------ |
| `Map`     | 键值对         | 键转为字符串（同纯对象） |
| `Set`     | 值数组         |                          |
| `WeakMap` | `{}`（仅结构） | 条目不可枚举             |
| `WeakSet` | `[]`（仅结构） | 条目不可枚举             |

### 二进制数据

| 类型                | 序列化方式      | 说明                        |
| ------------------- | --------------- | --------------------------- |
| `Int8Array`         | Base64 + 元数据 |                             |
| `Uint8Array`        | Base64 + 元数据 |                             |
| `Uint8ClampedArray` | Base64 + 元数据 |                             |
| `Int16Array`        | Base64 + 元数据 |                             |
| `Uint16Array`       | Base64 + 元数据 |                             |
| `Int32Array`        | Base64 + 元数据 |                             |
| `Uint32Array`       | Base64 + 元数据 |                             |
| `Float32Array`      | Base64 + 元数据 |                             |
| `Float64Array`      | Base64 + 元数据 |                             |
| `BigInt64Array`     | Base64 + 元数据 |                             |
| `BigUint64Array`    | Base64 + 元数据 |                             |
| `ArrayBuffer`       | Base64 + 元数据 |                             |
| `DataView`          | Base64 + 元数据 |                             |
| Node.js `Buffer`    | Base64 + 元数据 | 浏览器中恢复为 `Uint8Array` |

### 函数

| 类型       | 序列化方式 | 说明 |
| ---------- | ---------- | ---- |
| 普通函数   | 保留函数体 |      |
| 箭头函数   | 保留函数体 |      |
| 异步函数   | 保留函数体 |      |
| 生成器函数 | 保留函数体 |      |
| 方法       | 保留函数体 |      |

> **闭包限制：** 函数体会被序列化，但词法闭包**不会**自动捕获。使用 `parse()` 的 `closure` 选项提供外部变量，或将值附加到命名函数对象上。

### Symbol

| 类型                         | 序列化方式                   | 说明 |
| ---------------------------- | ---------------------------- | ---- |
| 知名 Symbol                  | 名称（如 `Symbol.iterator`） |      |
| 全局 Symbol (`Symbol.for()`) | 键字符串                     |      |
| 局部 Symbol                  | 描述作为值                   |      |
| Symbol 对象键                | 支持知名和全局 Symbol        |      |

### 高级特性

- **属性描述符**（writable、configurable、enumerable、getter/setter）
- **原型链**（原型上的方法和属性）
- **循环引用**（追踪并恢复）
- **自定义 `toJSON` / `fromJSON`** 方法受尊重
- **`JSON.rawJSON()`** 对象（运行时支持时）
- **不可枚举属性**（当 `preserveDescriptors: true` 时）

## 不支持的内容

- 私有类字段和方法（外部不可访问）
- 原生函数（源码为 `[native code]`）
- `Function.prototype.bind()` 结果（变为类原生）
- `WeakMap`/`WeakSet` 条目（不可枚举）
